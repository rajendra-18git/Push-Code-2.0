✦ Deep Code Engine (v1.2.0)

How CodePush Captures 100% of Your Code Without Truncation

Competitive coding platforms use virtualized code editors (Monaco, Ace, CodeMirror 6) that remove invisible code lines from the DOM. Standard Chrome extensions only scrape HTML, causing long solutions to be cut off. CodePush bypasses this with a direct in-memory execution bridge:

🧠

Direct Monaco Model Inspection

Uses page-bridge.js running directly in the page's execution context to query window.monaco.editor.getModels(), retrieving the complete, un-truncated solution regardless of file length or scroll position.

⚡

Real-Time Keystroke Sync

Debounced change listeners mirror your editor changes instantly. The floating pill updates its line count badge live, and the side panel stays continuously in sync with the active problem tab.

🏆

Auto-Verdict Detection

A high-speed DOM observer watches for "Problem Solved Successfully", "Accepted", or "100/100" submission verdicts, immediately turning the floating widget into a celebratory one-click push badge.

Download the codepush-extension.zip file and unzip it into a folder on your computer. Important: Keep this folder permanently on your disk — do not delete it after loading.

Developer mode ON (Located in top-right corner of Chrome)
4

Click "Load unpacked"

Click the Load unpacked button in the top toolbar and select the unzipped folder containing manifest.json.

📁 Load unpacked Select the root unzipped folder that directly contains manifest.json.

Click the puzzle-piece icon in your browser toolbar, find CodePush, and click the pin icon to keep the extension accessible.

⚠️

Troubleshooting: "Manifest file is missing or unreadable"

If Chrome displays this error, you selected the outer wrapper folder instead of the folder directly containing manifest.json. Make sure the folder you select has manifest.json directly inside it (e.g. codepush-extension/manifest.json).

✦ Questions & Answers

Frequently asked questions

Everything you need to know about CodePush privacy, compatibility, and workflow.

Is CodePush completely free to use? +
Yes, 100% free with no paywalls, subscriptions, or hidden limits. You can push as many solutions as you wish directly into your own GitHub repository.
Is my GitHub Personal Access Token safe? +
Absolutely. CodePush has no backend servers or database. Your token is stored solely inside your browser's private chrome.storage.local sandboxed storage. The token is transmitted strictly to api.github.com via secure HTTPS. You retain full control and can revoke it anytime.
Which programming languages and platforms are supported? +
All languages supported by GeeksforGeeks, HackerRank, CodeChef, and LeetCode are supported. CodePush automatically maps the detected language to its standard file extension (e.g. .py for Python, .cpp for C++, .java for Java, .js for JavaScript, .c for C, .go for Go, .rs for Rust, .ts for TypeScript, etc.).
What if the target repository already exists? +
CodePush detects that the repository already exists on your GitHub account and simply creates a new commit in the appropriate platform folder without overwriting unrelated files.
What happens if I push the same problem again? +
Re-pushing updates the existing file with your new code by querying the existing Git blob SHA and pushing an update commit. This preserves your complete commit history without creating duplicate files.
Does it work on Brave, Edge, and other Chromium browsers? +
Yes! Microsoft Edge, Brave, Opera, Arc, and Vivaldi all share the Chromium engine. Simply open edge://extensions or brave://extensions, turn on Developer Mode, and click "Load unpacked".
How does automatic platform and code detection work? +
CodePush runs a dedicated dual-engine system. As you browse, it recognizes the coding platform (GeeksforGeeks, HackerRank, CodeChef, or LeetCode) and injects a lightweight main-world bridge (page-bridge.js) that directly queries the in-memory editor models (Monaco Editor, Ace, CodeMirror). This ensures 100% of your code is captured without missing lines caused by virtual scrolling.
How does CodePush know when my problem is solved? +
A built-in DOM observer continuously monitors submission verdict elements on each platform (such as "Problem Solved Successfully" on GFG, "Accepted" on LeetCode/CodeChef, or "Congratulations!" on HackerRank). Once all test cases pass, the floating pill widget automatically updates to 🎉 Push Solved Code and notifies you that your code is verified and ready to commit.
Why do I need to enable "Developer mode"? +
"Developer mode" is the official Chromium feature that allows developers to load unpacked extensions directly from source files without going through the Chrome Web Store. It guarantees that the code running in your browser is 100% transparent and inspectable.
